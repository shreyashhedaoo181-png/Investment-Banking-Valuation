# 📊 Investment Banking Comparable Company Analysis (Comps)

## Overview

This project demonstrates a professional Comparable Company Analysis (Comps), one of the most widely used valuation methodologies in Investment Banking, Equity Research, and Corporate Finance.

The analysis compares leading Indian Information Technology (IT) companies using key financial and valuation metrics to evaluate relative performance and identify companies that may be undervalued, fairly valued, or overvalued.

---

## Project Objectives

- Perform relative valuation using Comparable Company Analysis (Comps).
- Compare financial performance across leading Indian IT companies.
- Analyze valuation multiples used in investment banking.
- Develop an Excel-based financial model and dashboard.
- Generate investment recommendations based on peer comparison.

- Debt-to-Equity Ratio

## Methodology

1. Selected comparable companies from the Indian IT industry.
2. Collected publicly available financial data.
3. Standardized and organized financial information.
4. Compared valuation multiples across peer companies.
5. Evaluated relative valuation and financial performance.
6. Presented findings using Excel dashboards and charts.
